# SEO standard — read this before writing any blog post

Five files:

| File | Use |
|---|---|
| **README.md** (this) | The process, and the checklist that must pass before a post ships. |
| **facts.md** | Every number we may publish, with source URL. **Nothing outside this file goes in an article.** |
| **keywords.md** | Researched clusters. Pick the primary keyword from here. |
| **used-keywords.md** | Primary keywords already claimed. Never reuse one. |
| **voice.md** | Tone, reading level, humour, opinions, stats, stories. |

---

## The one rule that outranks the rest

The product promise is **"echt door een docent gevalideerd, geen AI."** That is a constraint on
the content, not a slogan. Concretely:

- **Every number is sourced or it is cut.** `facts.md` or nothing. If a competitor states a
  figure and we cannot source it, we say *that* — naming the gap is more citable than repeating
  the guess. See the pass-norm passage in `facts.md` §2 for the model.
- **No invented social proof.** No testimonials, no `AggregateRating`, no "duizenden studenten".
  Three fabricated testimonials came across in the KNM fork and were removed. The product has no
  customers yet.
- **Never frame grading as "the AI grades your answer."** Rubric-driven: the docent authors the
  rubric and model answers, a model applies them, the docent reviews.

## Process

### 1. Pick the keyword
- From `keywords.md`, not already in `used-keywords.md`.
- Filters: difficulty ≤30, volume ≥100/mo, **informational intent only**.
- Add 4–5 secondary keywords forming one coherent cluster.
- **Append the primary keyword to `used-keywords.md` when the post ships.**

**The intent filter is the one people skip, and it is the one that matters here.** Every
`inburgeringsexamen oefenen` / `oefenexamen A2` SERP is a **tool SERP** — DUO and
`nt2taalmenu.nl` rank there with 150–250-word exam pages. A blog post cannot win those. Those
queries belong to `/oefenen/[skill]` and `/oefenexamen/[skill]`. The blog takes *explanatory*
queries only.

### 2. SERP research — before writing a word
- Search the primary keyword on Google.nl.
- Open the top 3. Record format (listicle / guide / tutorial / comparison), word count, topics.
- **Match their format, and land within 10% of their average word count.**

Two honest limitations in this environment, so nobody wastes an hour rediscovering them:
- **`google.nl` is not fetchable** — it 302s to `consent.google.nl`. Bing returns unrelated
  results for Dutch exam queries and surfaces no PAA module.
- **Verbatim "People Also Ask" therefore cannot be scraped here.** Three ways to get it for real:
  Search Console query data once the site has impressions; the installed **`seo-dataforseo`**
  skill (real volume, KD *and* PAA — it replaces every `[EST]` in `keywords.md`); or a manual
  pass in a Dutch-IP browser.
- Until then, harvest question-form headings from currently-ranking pages as a **proxy**, and
  label them as such in the post's notes. Do not present proxies as verified PAA.

### 3. Content requirements
- Cover every topic all three top results discuss.
- Add 1–2 topics they missed. Our reliable differentiators: **sourced facts**, the
  **exam-day rules** in `facts.md` §6 that nobody publishes, and the **DUO supplies 3–4 practice
  exams, we supply 10** line.
- **Answer the main question in the first 100 words**, directly, before any preamble. This is what
  wins the featured snippet and the AI Overview.
- FAQ section, 4–8 questions.

### 4. Voice
Apply `voice.md`. The non-obvious constraint: **the reader is learning Dutch at A2.** A Dutch
post written at native journalistic level fails its audience regardless of how well it ranks.

### 5. Images
- One hero per post; optionally one above an H2 where it genuinely helps. Not decoration per
  section.
- Source via `/api/pexels-search` (needs `PEXELS_API_KEY`). Save to `public/images/blog/<slug>.jpg`,
  under ~150 KB. `next.config.ts` has no `images.remotePatterns`, so images must be local.
- Record attribution in `resources/images/CREDITS.md`.
- Descriptive alt text carrying the primary keyword naturally. Never keyword-stuff alt text.

### 6. Where the post lives
**Not** `app/blog/[slug]/page.jsx`. This project is App Router + i18n + TypeScript:
- Post content is **data**: an entry in `data/blog-posts.ts` (`BlogPost`), with `articleHtml` as an
  HTML string. Per-locale bodies go in `translations[locale].articleHtml`.
- The routes already exist and need no changes per post:
  `app/[locale]/(main)/blog/page.tsx` and `app/[locale]/(main)/blog/[slug]/page.tsx`.
- Metadata, canonical, hreflang, OG and all JSON-LD are generated by the route from the post
  data. Do not hand-roll them per post.
- A locale without a translated body is `noindex`ed automatically via `hasTranslation()` — leave
  it untranslated rather than shipping a thin duplicate.

## On-page checklist — verify every item before declaring a post done

- [ ] Primary keyword in the first 100 words
- [ ] Exactly one `<h1>` on the page
- [ ] H2 per major section, in a sensible outline
- [ ] The main question answered directly at the top
- [ ] 4–8 FAQ questions (real PAA if available, else labelled proxies)
- [ ] 2–3 internal links to related pages (`/oefenen`, `/oefenexamen/[skill]`, `/docent`, other posts)
- [ ] 2–3 external links to authoritative sources (inburgeren.nl, rijksoverheid.nl, wetten.overheid.nl)
- [ ] **Every number traced to `facts.md` and wrapped in a `FactBox`**
- [ ] Nothing from the `facts.md` §9 do-not-publish list
- [ ] Meta title **≤60 chars**, primary keyword near the front
- [ ] Meta description **140–160 chars** (stricter than the generic ~155), includes primary keyword
- [ ] Every image has descriptive alt text
- [ ] `BlogPosting` JSON-LD with `datePublished` + `dateModified`
- [ ] `BreadcrumbList` + `FAQPage` JSON-LD
- [ ] Canonical set per locale (not hardcoded to `/nl`)
- [ ] Open Graph title, description, image
- [ ] Post added to the sitemap (automatic via `app/sitemap.ts` — confirm it appears)
- [ ] Primary keyword appended to `used-keywords.md`
- [ ] No emoji anywhere (project rule — lucide icons only)
- [ ] Links use `Link` from `@/i18n/navigation`, never bare `<a>` (bare `<a>` drops the locale prefix)

## Publishing cadence
Don't dump a large batch at once. 1 post/day for the first fortnight, 2/day weeks 3–4, 3/day from
month 2. After publishing, request indexing in Search Console (~10 URLs/day max).

## Off-page
Not a priority yet. When it is: broken-backlink swaps, guest posts, journalist queries, and
selective paid placements. **Never** PBNs or bulk cheap backlinks — Google detects them and the
penalty is permanent.
